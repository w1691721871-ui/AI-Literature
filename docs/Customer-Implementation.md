# Customer Implementation Flow

ResearchOS supports a staged FDE implementation rather than an unbounded AI rollout.

1. **Discovery** — confirm customer goals, source systems, roles, data ownership and success criteria.
2. **Workspace setup** — create the organization, Workspace, memberships and role matrix.
3. **Knowledge onboarding** — import only authorized source material through the approved ingestion path; confirm diagnostics before research use.
4. **Mission configuration** — define objectives, available skills, Evidence requirements, approval gates and expected outputs.
5. **Controlled pilot** — run representative Missions with reviewers, audit history and release gates enabled.
6. **Acceptance** — validate Evidence traceability, approval behavior, artifact quality, permissions and operational recovery.
7. **Handover** — provide role training, governance ownership, deployment runbook and a documented AI risk boundary.

Customer acceptance must distinguish validated platform behavior from unverified research outcomes.
