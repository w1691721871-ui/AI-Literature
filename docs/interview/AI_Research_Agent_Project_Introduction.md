# AI Research Agent

## 面向科研场景的智能文献理解与知识探索平台

**项目性质：AI Agent 产品原型（Product Prototype）**

AI Research Agent 面向需要持续阅读、比较和沉淀科研资料的研究者，提供从单篇论文理解到多论文知识探索的一体化工作空间。产品将非结构化 PDF 文献转化为可追问、可检索、带证据来源的研究洞察，帮助用户把时间投入到研究判断而非重复的信息整理中。

## 1. 项目背景

科研人员通常需要在短时间内处理大量论文：单篇阅读需要反复定位研究背景、方法与实验结果；多篇论文之间的方法差异和研究趋势难以快速建立联系；已读资料也不容易沉淀为后续可复用的知识。

AI Research Agent 以“用户目标 + 文献资料 + Agent 工作流”为入口，让系统主动理解任务、组织分析步骤，并将回答建立在已解析文献的证据之上。

## 2. 产品定位

AI Research Agent 是一个面向科研人员的 AI Agent 产品原型。它覆盖以下闭环：

`论文上传 → AI 解析 → 智能分析 → 知识沉淀 → 多论文探索 → 研究报告生成`

产品并非只输出摘要，而是围绕研究任务组织信息、检索证据并给出结构化研究结论。

## 3. 核心功能

### Paper Analysis Agent

- 对单篇论文进行深度理解，提取研究背景、研究方法、创新点、主要发现与局限性。
- 根据用户任务与角色选择分析重点，生成结构化结论。
- 以当前论文内容为上下文，支持连续追问。

### Research Knowledge Base

- 支持论文上传、论文库管理和历史分析报告查看。
- 复用 PDF 解析结果完成文本切分、Embedding 向量化和 FAISS 索引构建。
- 通过 SQLite 保存论文元信息、分析记录和问答历史，避免把论文全文直接返回到前端。

### Research Copilot

- 支持多论文知识问答、方法路线比较、文献综述、研究趋势与研究空白探索。
- 包含 Query Rewrite、Hybrid Retrieval、Rerank、Citation Evidence 与 Retrieval Quality Evaluation。
- 返回引用论文、章节级证据与检索质量信息，帮助用户理解回答依据。

## 4. 产品架构

```text
Vue3 CDN
   ↓
FastAPI
   ├── PaperAnalysisAgent（单篇论文分析）
   └── ResearchAgent（多论文知识探索）
       ├── ResearchPlanner
       ├── Query Rewrite
       ├── Retriever
       ├── Reranker
       └── Report Generator
   ↓
SQLite（论文、分析记录、问答历史）
   ↓
FAISS + Embedding（知识片段索引）
   ↓
Qwen-plus
```

## 5. 项目成果

- 独立完成 AI Agent 产品原型的需求梳理、交互设计和全链路实现。
- 打通论文上传、单篇分析、论文库、RAG 多论文问答、引用展示与报告生成流程。
- 通过 Agent 执行摘要、引用证据和检索质量信息增强结果可解释性。
- 已完成线上部署，支持直接体验产品原型。

## 6. 产品思考

这个产品原型验证了 AI Agent 在科研知识场景中的落地方向：从“帮助阅读一篇论文”升级为“围绕研究任务组织知识与辅助判断”。

后续可继续演进为科研团队知识库、企业技术文档智能助手、研究趋势发现工具和团队知识协作空间。
