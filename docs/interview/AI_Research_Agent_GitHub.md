# AI Research Agent GitHub Repository

GitHub：[w1691721871-ui/AI-Literature](https://github.com/w1691721871-ui/AI-Literature)

该仓库用于展示 AI Agent 产品原型的完整实现，包含：

- FastAPI 后端
- Vue3 CDN 前端
- PaperAnalysisAgent
- ResearchAgent
- RAG Pipeline
- FAISS 向量检索
- SQLite 数据管理
- Render 部署配置

项目重点展示从产品需求、AI Agent 工作流设计到 RAG 能力落地与线上体验的完整闭环。仓库不包含真实 API Key、本地论文文件、SQLite 数据库或向量索引文件。
