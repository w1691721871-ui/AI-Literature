# 比赛 Demo 指引

1. 在“我的论文库”上传 5 篇可提取文本的 PDF，等待每篇状态显示为 `ready`。
2. 进入“知识问答”，选择论文范围，输入“比较不同论文的方法路线”。
3. 展示 Agent 执行过程：问题理解、任务规划、Query Rewrite、检索、重排、结论生成。
4. 展示“知识库检索质量”、回答中的证据标记，以及可点击的引用论文片段。
5. 在“研究任务中心”选择“论文综述”，生成包含研究背景、核心问题、技术路线、方法比较、创新点、不足、未来研究方向和参考论文的报告。
6. 点击“历史知识问答”恢复一条记录，说明回答与引用可复查。
7. 删除一篇测试论文后刷新论文库，说明关联切片、RAG 记录与索引映射会同步清理。

建议使用真实、可公开的论文 PDF；模型结果为研究辅助信息，需结合原文、实验数据与领域专家判断复核。
