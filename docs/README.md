## Public documentation principle

The current product is **AI Research Employee for Enterprise Research Teams**. Public material should describe the supported enterprise workflow: **Mission → Evidence → Human Review → Artifact Delivery → Organizational Knowledge**. Historical implementation material remains outside the public reading path.
