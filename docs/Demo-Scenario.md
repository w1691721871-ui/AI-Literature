# Demo Scenario: Low-Carbon Building Material Research

**Classification: DEMO / EXAMPLE ONLY.** This scenario illustrates workflow behavior and is not a customer case or a research conclusion.

1. A customer describes a low-carbon building-material innovation question.
2. A Workspace member creates a Mission with the customer need and authorized context.
3. ResearchOS creates a reviewable plan and uses only indexed Evidence.
4. Evidence gaps or conflicts remain explicit; the system does not manufacture papers, evidence or conclusions.
5. A reviewer verifies the Evidence or requests changes.
6. The Delivery skill produces a draft artifact linked to Evidence and approval state.

Demo mode only controls identity provisioning when explicitly enabled by deployment configuration. It never creates a real customer, invents research data or bypasses RBAC.
